Objetivo do site

Este site foi desenvolvido com o objetivo de apresentar informações sobre a Computação em Nuvem de maneira simples e fácil de entender.

Durante as páginas, são apresentados o conceito, as principais utilidades e uma explicação sobre o funcionamento dessa tecnologia.

O site utiliza o framework Bootstrap para auxiliar na construção do layout e na responsividade das páginas.

Tecnologias utilizadas

HTML

Estrutura das páginas.

CSS

Personalização visual do site.

Bootstrap

Framework utilizado no projeto.
